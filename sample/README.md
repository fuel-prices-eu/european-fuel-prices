# Samples

A few hundred rows of each table, so the structure can be seen without downloading. Full files: https://www.fuel-prices.eu/research/ and the Zenodo record (see the main README).

| file | rows in sample | selection | licence |
|---|---|---|---|
| fp-d1-eu-weekly-panel_sample.csv | 270 | last 10 bulletin weeks | CC BY 4.0 (European Commission data) |
| fp-d1-eu-weighted-average_sample.csv | 104 | last 52 weeks | CC BY 4.0 (European Commission data) |
| fp-d2-national-daily_sample.csv | 164 | last 4 days | our statistics CC BY 4.0; source terms in `source_terms` |
| fp-d3-regional-daily_sample.csv | 194 | last day, diesel | our statistics CC BY 4.0; source terms in `source_terms` |
| fp-d4-stations-fr_sample.csv | 300 | France, last day, first 300 station/fuel rows | **Licence Ouverte 2.0 (Etalab)** — station-level source data from prix-carburants.gouv.fr, not CC BY 4.0 |

Each sample keeps the CSV header and the source lines (`#`) of the full file. The station-level France sample illustrates D4, which is published only on the site, under the licence of each national source.
